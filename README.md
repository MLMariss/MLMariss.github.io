# mlmariss.github.io

The root page of `https://mlmariss.github.io/`. It exists so Google can read a site name
("MLMariss") for everything hosted under this address, including
[QTPD](https://mlmariss.github.io/SteamQTPD/), and to give visitors who trim the URL a way in
instead of a 404.

`robots.txt` here is the one search engines read for the whole address; it points them at the
QTPD sitemap.
